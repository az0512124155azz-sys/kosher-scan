חיבור המערכת

האפליקציה והסוכן, מחוברים.

1. חיבור אוטומטי לאפליקציות

לאחר הפעלת השירות ופרסום הגדרות החיבור, כל האפליקציות מתחברות אוטומטית. המשתמשים אינם צריכים להזין כתובת או קוד.

ההפעלה מתבצעת פעם אחת בניהול המערכת. תוצאת ״לא ידוע״ נשלחת ברקע, בלי כפתורים או הודעות טכניות באפליקציה.

2. חיבור טלגרם

לאחר ההפעלה, שלח לבוט את הפקודה הזו כדי לחבר את השיחה שלך:

רק השיחה המחוברת מקבלת תמונות ופרטי מוצרים.

הסוכן אוסף מידע והצעות. תשובה מתפרסמת באפליקציה לאחר אימות, עם תאריך תוקף.
